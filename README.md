# 🧠 SFM Builder Codes

A visual node-based editor for creating scripts for the **Super Factory Manager (SFM)** mod in Minecraft.

## 🚀 About

SFM Builder is a drag-and-drop interface designed to simplify the creation of complex automation scripts.
Instead of writing everything manually, users can build logic visually and generate valid SFM code instantly.

## ⚙️ Features

* 🧩 Node-based visual editor (drag & drop)
* 🔀 Nested logic (IF inside IF)
* 🔁 Loop support (`each`)
* 🧠 `forget` block for execution separation
* 📥 Input / 📤 Output with multiple destinations
* 🔴 Redstone control
* ✍️ Raw block for custom SFM code
* 🔍 Item autocomplete system
* 🔄 Reverse parser (code → UI)
* 💾 Template saving system

## 🎯 Goal

The goal of this project is to provide a complete and flexible tool capable of handling **any SFM automation scenario**, focusing on:

* Productivity
* Visual clarity
* Error reduction
* Ease of use
